# Medieval Castle Construction

- Source: https://3dassets.dev/packs/medieval-castle-construction
- Manifest: https://3dassets.dev/api/v1/packs/medieval-castle-construction
- Licence: CC0 1.0 Universal
- Contents: 149 modular GLB models and one assembled castle courtyard starter scene.
- The importer validates GLB v2 headers, exact byte lengths, CDN host and manifest licence before cataloguing files.
- The assembled scene is intended as a large landmark; collision and navigation must be supplied by the game.
