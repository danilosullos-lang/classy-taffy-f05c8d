The castle pack is imported by import_rpg_world_assets.py. It is fetched from the public 3DAssets.dev manifest only after checking the exact CC0 1.0 Universal license label. The importer requires exactly 149 entries, restricts every CDN URL to cdn.3dassets.dev, validates every GLB v2 byte length, and writes a catalog plus the assembled starter scene. The world-assets workflow is restricted to pushes on main so a feature-branch push cannot publish the feature branch directly to main.
