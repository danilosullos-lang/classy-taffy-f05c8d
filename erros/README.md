# Erros do Aetheria RPG

Coloque nesta pasta capturas de tela dos bugs encontrados no jogo.

## Como enviar
- Envie cada print original, sem editar.
- Se possível, nomeie os arquivos com uma descrição curta, por exemplo `personagem-invisivel.png` ou `npc-sem-textura.jpg`.
- Se souber, informe no nome ou na descrição onde o erro aconteceu e como reproduzir.

As imagens desta pasta serão usadas para analisar os problemas visuais e funcionais do jogo.
