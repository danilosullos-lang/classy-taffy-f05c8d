# Player character animations

The Lyra player GLB can be enhanced with the Quaternius Universal Animation Library 1 and 2.

- Official source: https://quaternius.com/packs/universalanimationlibrary.html
- Official license: CC0 (public domain dedication); commercial use and modification allowed.
- Animation packs are mirrored for automated build input from https://github.com/NafisRayan/Animate-Rigged-Humanoid-No-Blender
- The importer matches animation bone names to the existing Lyra skeleton and refuses to replace the current model unless at least 20 clips and 100 channels can be retargeted.
- The game loads animation clips from the GLB and selects idle, walk, run, jump, attack, block, hit, roll, land and death clips by name when present.

The original player asset is preserved in Git history before the first successful merge.
